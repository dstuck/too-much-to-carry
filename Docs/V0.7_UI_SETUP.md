# v0.7 UI Setup Guide

This guide walks through setting up the timer display and game over screen UI elements.

## Prerequisites

- Canvas already exists in your scene (should be present from previous versions)
- GameManager GameObject needs to be created (see GameManager setup below)

## Part 1: Timer Display Setup

### Step 1: Create Timer Text GameObject

1. In the Hierarchy, right-click on the **Canvas** → **UI** → **Text - TextMeshPro**
2. Rename it to **"TimerDisplay"**
3. Position it at the top-center of the screen:
   - **RectTransform**: 
     - Anchor: Top-Center
     - Position: (0, -30, 0) or adjust as needed
     - Width: 200, Height: 50

### Step 2: Configure Timer Text

1. Select the **TimerDisplay** GameObject
2. In the **TextMeshPro - Text (UI)** component:
   - **Text**: "02:00" (initial display)
   - **Font Size**: 36-48 (adjust to preference)
   - **Alignment**: Center (both horizontal and vertical)
   - **Color**: White or your preferred color
   - **Font Style**: Bold (optional)

### Step 3: Add TimerDisplay Component

1. With **TimerDisplay** selected, click **Add Component**
2. Search for and add **TimerDisplay** script
3. The script will automatically find the TextMeshProUGUI component, but you can drag it to the **Timer Text** field if needed

**Result**: Timer should now display and count down when the game starts.

## Part 2: Game Over Screen Setup

### Step 1: Create Game Over Panel

1. Right-click on **Canvas** → **UI** → **Panel**
2. Rename it to **"GameOverPanel"**
3. Configure the Panel:
   - **RectTransform**:
     - Anchor: Stretch-Stretch (all corners)
     - Left: 0, Right: 0, Top: 0, Bottom: 0 (fills entire screen)
   - **Image** component:
     - **Color**: Black with ~80% opacity (Alpha: 200/255)
     - This creates a semi-transparent overlay

### Step 2: Create Title Text

1. Right-click on **GameOverPanel** → **UI** → **Text**
2. Rename to **"TitleText"**
3. Configure:
   - **RectTransform**:
     - Anchor: Top-Center
     - Position: (0, -50, 0)
     - Width: 400, Height: 60
   - **Text**:
     - **Text**: "Game Over"
     - **Font Size**: 48
     - **Alignment**: Center
     - **Color**: White
     - **Font Style**: Bold

### Step 3: Create Metrics Container

1. Right-click on **GameOverPanel** → **UI** → **Panel**
2. Rename to **"MetricsContainer"**
3. Configure:
   - **RectTransform**:
     - Anchor: Middle-Center
     - Position: (0, 0, 0)
     - Width: 600, Height: 400
   - **Image** component:
     - **Color**: Dark gray or semi-transparent (optional, for visual grouping)
     - Or disable Image component if you don't want a background

### Step 4: Create Bar Chart Structure (Using Prefab)

We'll create one metric bar as a prefab, then reuse it for the other two metrics.

#### 4a: Create First Metric Bar (Baby Happiness)

1. Right-click on **MetricsContainer** → **UI** → **Panel**
2. Rename to **"MetricBarContainer"** (generic name for prefab)
3. Configure:
   - **RectTransform**:
     - Anchor: Top-Left
     - Position: (-200, -50, 0)
     - Width: 150, Height: 250
   - Remove or disable **Image** component (we don't need background)

4. **Create Label**:
   - Right-click on **MetricBarContainer** → **UI** → **Text**
   - Rename to **"MetricLabel"** (generic name)
   - **RectTransform**: Anchor Top-Stretch, Position (0, -10, 0), Width: 150, Height: 30
   - **Text**: "Baby Happiness", Font Size: 18, Alignment: Center

5. **Create Bar Background**:
   - Right-click on **MetricBarContainer** → **UI** → **Image**
   - Rename to **"BarBackground"** (generic name)
   - **RectTransform**: Anchor Bottom-Center, Position (0, 20, 0), Width: 100, Height: 200
   - **Image**: Color: Dark gray (e.g., RGB: 50, 50, 50)

6. **Create Bar Fill**:
   - Right-click on **BarBackground** → **UI** → **Image**
   - Rename to **"BarFill"** (generic name)
   - **RectTransform**: 
     - Click the anchor preset button (square icon in top-left of RectTransform)
     - Hold Shift+Alt and click **Bottom-Left** preset (this anchors to bottom-left and stretches)
     - Or manually: Set Anchor Min: (0, 0), Anchor Max: (0, 0), Pivot: (0, 0)
     - Position: (0, 0, 0)
     - Width: 100, Height: 200
   - **Image**: 
     - Color: Green (or your preferred color)
     - **Note**: The `GameOverScreen` script will automatically set Image Type to "Filled" at runtime
     - You can optionally set it manually in Inspector: **Type** dropdown → **Filled**, **Fill Method** → **Vertical**, **Fill Origin** → **Bottom**
     - **Fill Amount**: 0 (starts empty)

7. **Create Prefab**:
   - Drag **MetricBarContainer** from Hierarchy to your **Assets/Prefabs** folder (or create Prefabs folder if needed)
   - This creates a prefab you can reuse
   - Rename the prefab to **"MetricBarPrefab"** or similar

8. **Rename Instance for Baby Happiness**:
   - In Hierarchy, rename **MetricBarContainer** to **"BabyHappinessContainer"**
   - Rename **MetricLabel** child to **"BabyHappinessLabel"**
   - Rename **BarFill** child (inside BarBackground) to **"BabyHappinessBar"**

#### 4b: Create Steaks Cooked Bar (Using Prefab)

1. Drag **MetricBarPrefab** from Project window into **MetricsContainer** in Hierarchy
2. Rename the instance to **"SteaksCookedContainer"**
3. Configure:
   - **RectTransform**:
     - Anchor: Top-Center
     - Position: (0, -50, 0)
4. Update child components:
   - **MetricLabel** → Rename to **"SteaksCookedLabel"**
     - **Text**: "Steaks Cooked"
   - **BarFill** (inside BarBackground) → Rename to **"SteaksCookedBar"**
     - **Image**: Color: Red/Brown (meat color)

#### 4c: Create Laundry Folded Bar (Using Prefab)

1. Drag **MetricBarPrefab** from Project window into **MetricsContainer** in Hierarchy
2. Rename the instance to **"LaundryFoldedContainer"**
3. Configure:
   - **RectTransform**:
     - Anchor: Top-Right
     - Position: (200, -50, 0)
4. Update child components:
   - **MetricLabel** → Rename to **"LaundryFoldedLabel"**
     - **Text**: "Laundry Folded"
   - **BarFill** (inside BarBackground) → Rename to **"LaundryFoldedBar"**
     - **Image**: Color: Blue or White (laundry color)

### Step 5: Create Restart Button

1. Right-click on **GameOverPanel** → **UI** → **Button - Text**
2. Rename to **"RestartButton"**
3. Configure:
   - **RectTransform**:
     - Anchor: Bottom-Center
     - Position: (0, 50, 0)
     - Width: 200, Height: 50
   - **Button** component: Default settings are fine
   - **Text** (child): "Restart", Font Size: 24, Alignment: Center

### Step 6: Add GameOverScreen Component

**Important**: The `GameOverScreen` component must be on an **active GameObject** (like Canvas or a parent that stays active), NOT on the inactive GameOverPanel itself. If placed on an inactive GameObject, it won't subscribe to events.

**Option A (Recommended)**: Place component on Canvas
1. Select the **Canvas** GameObject (or another active parent)
2. Click **Add Component** → Search for **GameOverScreen**

**Option B**: Place component on GameOverPanel (if you keep panel active but hidden)
1. Select the **GameOverPanel** GameObject
2. **Keep the panel active** (don't uncheck the checkbox)
3. Instead, hide it visually by setting the Panel's Image alpha to 0 or moving it off-screen
4. Click **Add Component** → Search for **GameOverScreen**
3. In the **GameOverScreen** component, assign references:
   - **Game Over Panel**: Drag **GameOverPanel** itself here
   - **Restart Button**: Drag **RestartButton** here
   - **Baby Happiness Bar**: Navigate to **BabyHappinessContainer** → **BarBackground** → **BabyHappinessBar** and drag it here
   - **Steaks Cooked Bar**: Navigate to **SteaksCookedContainer** → **BarBackground** → **SteaksCookedBar** and drag it here
   - **Laundry Folded Bar**: Navigate to **LaundryFoldedContainer** → **BarBackground** → **LaundryFoldedBar** and drag it here
   - **Baby Happiness Label**: Drag **BabyHappinessLabel** here (optional)
   - **Steaks Cooked Label**: Drag **SteaksCookedLabel** here (optional)
   - **Laundry Folded Label**: Drag **LaundryFoldedLabel** here (optional)
   - **Max Bar Height**: 200 (default, matches bar height)
   - **Use Filled Image**: ✓ (checked, recommended)

**Note**: When using prefabs, make sure to assign the actual instance references (from the scene), not the prefab asset references.

### Step 7: Initial State

1. Select **GameOverPanel** in Hierarchy
2. In Inspector, **uncheck** the GameObject's active checkbox (top-left)
   - This hides it initially (script will show it when game ends)

## Part 3: GameManager Setup

### Step 1: Create GameManager GameObject

1. In Hierarchy, right-click → **Create Empty**
2. Rename to **"GameManager"**
3. Click **Add Component** → Search for **GameManager**
4. Configure:
   - **Game Duration**: 120 (2 minutes in seconds)
   - **Max Steaks For Scoring**: 10
   - **Max Laundry For Scoring**: 10

---

## Part 4: Optional - UIManager Integration

If you want UIManager to coordinate everything:

1. Select the GameObject with **UIManager** component
2. In Inspector, find **UIManager** component
3. Assign references (optional, components will auto-find):
   - **Timer Display**: Drag **TimerDisplay** GameObject
   - **Game Over Screen**: Drag **GameOverPanel** GameObject

## Testing

1. Play the scene
2. Timer should count down from 02:00
3. When timer reaches 00:00, GameOverPanel should appear
4. Bar charts should display metrics
5. Click Restart button to reload the scene

---

## Troubleshooting

- **Timer not showing**: Make sure TimerDisplay GameObject is active and has TextMeshProUGUI component
- **Game over screen not appearing**: Check that GameOverPanel is initially inactive, and GameManager exists
- **Bars not filling**: Ensure bar Images have Image Type set to "Filled" and Fill Method to "Vertical"
- **Labels not updating**: Make sure labels are assigned in GameOverScreen component (optional but recommended)
