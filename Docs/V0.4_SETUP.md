# v0.4 Setup Instructions

This document describes the Unity Editor setup steps needed to complete v0.4 implementation.

## 1. Stove Tag Setup

1. In Unity Editor, go to Edit → Project Settings → Tags and Layers
2. Under Tags, add "Stove" (if not already present)
3. Select the Stove prefab in Assets/Prefabs/Stove.prefab
4. In Inspector, set the Tag to "Stove"

## 2. Raw Meat Prefab Setup

1. In Unity Editor, create an Empty GameObject in the scene
2. Name it "RawMeat"
3. Add components:
   - SpriteRenderer (assign a white/light gray steak sprite - you'll need to create/import one)
   - RawMeat script (the RawMeat.cs script should be available)
   - Collider2D (BoxCollider2D recommended, set as trigger) for interaction detection
4. In RawMeat component, configure:
   - Cook Time Min: 7
   - Cook Time Max: 12
   - Burn Time: 5
   - Raw Color: Red (default)
   - Cooked Color: Brown (default: 0.6, 0.4, 0.2)
   - Burnt Color: Black (default)
5. Position it where you want in the scene
6. Drag it from Hierarchy to Assets/Prefabs folder to create the prefab
7. You can create multiple raw meat instances by duplicating the prefab

## 3. Sprite Requirements

**Important**: The raw meat sprite should be:
- **White or light gray base**: This allows color tinting to show through properly
- **Avoid pure black areas**: Black areas won't show tint colors
- **Grayscale works best**: White = full tint visible, black = no tint visible

The sprite will be tinted:
- **Raw**: Red
- **Cooking**: Transitions from red to brown
- **Cooked**: Brown
- **Burnt**: Black

## 4. Scene Setup Notes

- The meat will automatically detect when placed on a stove (via "Stove" tag)
- Meat continues cooking even when held (GameObject stays active, like Baby)
- Cooking progress persists across pickups - timer resumes when put back down
- Each meat instance has its own random cook time (7-12s) set in Awake()
- Meat state (Raw/Cooking/Cooked/Burnt) and cooking progress are preserved when picked up

## 5. Testing Checklist

- [ ] Stove has "Stove" tag assigned
- [ ] Raw meat sprite is white/light gray for proper tinting
- [ ] Meat starts red (raw state)
- [ ] Meat detects stove placement correctly
- [ ] Meat transitions from red to brown while cooking (7-12s random)
- [ ] Meat becomes cooked (brown) at targetCookTime
- [ ] Meat transitions from brown to black during burn phase (5s after cooked)
- [ ] Meat becomes burnt (black) at targetCookTime + burnTime
- [ ] Picking up meat mid-cook preserves state and timer
- [ ] Putting meat back down resumes cooking from same progress
- [ ] Placing meat on non-stove surfaces doesn't cook (but preserves state)
- [ ] targetCookTime is set once per meat instance and never changes
